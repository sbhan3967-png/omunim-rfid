RFID Tags

Three tag types, one right choice

Pick the tag that fits how your showroom works.

🏷️

One-Time-Use RFID Tag

Designed for permanent tagging — the tail ties directly to the jewellery piece. The RFID printer maps the tag automatically during printing — fastest tagging with the least manual work.

  • Tail for jewellery attachment
  • Automatic mapping via printer
  • Streamlined high-volume tagging
🔄

Reusable RFID Tag

Hard PVC tag that can be reused across items. Mapping is done manually — no printer needed — using a desktop reader or handheld scanner.

  • No RFID printer required
  • Manual mapping, flexible process
  • Ideal if you already own tags
🛡️

AM + RFID Tag

Combines RFID identification with AM anti-theft technology — for showrooms that want stock management and security in one tag.

  • RFID + anti-theft in one
  • Pairs with AM + RFID gate
  • Maximum protection

Complete RFID Solution

One system. Three pillars.

Everything a jewellery showroom needs to tag, count and protect its stock — connected in Omunim, from counter to exit gate.

Pillar 1

Smart Showroom

Every piece is tagged at the counter and mapped in Omunim — the foundation the other two pillars run on.

  • One-time tail tags, auto-mapped by the TSC T820 during printing
  • Reusable PVC tags, mapped via desktop reader or Seuic AUTO Touch 2
  • Item code, weight and rate linked to each RFID number
Pillar 2

Stock Tally

Walk the showroom with the mobile app — the reader picks up dozens of tags at once, no piece-by-piece scanning.

  • Bulk reading, no line of sight needed
  • Instant Found / Missing (by exact code) / Extra report
  • Example: 500 items → 497 found → 3 missing identified
Pillar 3

Anti-Theft

The gate watches the exit so your staff doesn't have to — every tagged item passing through is detected and identified.

  • Automatic detection at the showroom exit
  • Item identified, billing status checked, alert raised
  • AM + RFID gate + tags for dual-layer protection
